About

SHEET 01/06

I started out chasing the gap between how an interface looked and how people actually needed it to work — a self-taught developer figuring things out one component at a time. That instinct never left; it just moved upmarket. Today I lead front-end architecture for applications that banks, insurers, and enterprise IT teams depend on to work correctly the first time, every time.

My focus is Angular at scale — component-based architecture, micro-frontends, design systems, and performance engineering for data-heavy, offline-capable applications. I led component engineering for Infosys's Finacle Design System, now deployed across 150+ banking clients worldwide, and I've since carried that same design-system discipline into fintech and enterprise platforms at Naviam and LTI Mindtree.

More recently, I've been embedding AI-assisted engineering — GitHub Copilot, Cursor, structured prompt workflows — directly into production delivery, which lifted my team's velocity by roughly 30% without loosening our standards on code review, accessibility, or test coverage. I'm currently deepening that into full-stack, AI-native engineering: building with LLM APIs, RAG pipelines, and agentic tooling alongside the Angular work.
